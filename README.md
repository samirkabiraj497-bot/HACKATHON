## Quick Launch:
- **Backend**: `cd campusflow-ai/backend && npm start` (Running on `http://localhost:5000`)
- **Frontend**: `cd campusflow-ai/frontend && npm run dev` (Running on `http://localhost:5173`)
- **Tests**: `cd campusflow-ai/backend && npm test` (11 of 11 tests passing)
